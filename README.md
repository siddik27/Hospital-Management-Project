# Hospital-Management-Project
A Java-based console application designed to manage hospital operations efficiently.
This project helps in maintaining patient records, doctor details, and appointments using Object-Oriented Programming (OOP) concepts.

 Features

Add, view, and manage patient details

Add and manage doctor information

Schedule and view appointments

Simple and user-friendly console interface

Uses OOP principles for modular and maintainable code

 Technologies Used

Java (Core Java, OOP)

File Handling for data storage
